Wallet 930 — Android Studio প্রজেক্ট
1. Android Studio (Koala বা নতুন) → File > Open → এই ফোল্ডার বাছুন, Gradle Sync শেষ হওয়া পর্যন্ত অপেক্ষা করুন।
2. Google Sheet-এ Share > "Anyone with the link" > Viewer দিন (না দিলে ডেটা লোড হবে না)।
3. APK: Build > Build Bundle(s)/APK(s) > Build APK(s)।
4. শিটের আইডি/ট্যাবের নাম বদলাতে MainActivity.kt-এর উপরের SHEET_ID ও TAB_NAME বদলান।

Android Studio ছাড়া APK (GitHub দিয়ে):
GitHub-এ নতুন repository বানিয়ে এই ফোল্ডারের সব ফাইল (.github সহ) আপলোড করুন → Actions ট্যাব → Build APK → শেষ হলে Artifacts থেকে Wallet930-APK ডাউনলোড করুন → ফোনে app-debug.apk ইনস্টল করুন।
